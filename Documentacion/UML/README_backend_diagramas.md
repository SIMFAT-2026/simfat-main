# Diagramas

Subir aqui:
- Diagrama de arquitectura
- Diagrama ER / modelo de datos
- Diagrama de casos de uso (s? aplica)

Formato recomendado de nombre:
`AAAA-MM-DD_tipo_diagrama_vN.ext`

Ejemplos actuales:
- `2026-04-21_arquitectura_actualizada_v1.md`
- `2026-04-21_mer_actualizado_v1.md`
- `2026-05-14_arquitectura_seguridad_rbac_jwt_backend_v1.md`
