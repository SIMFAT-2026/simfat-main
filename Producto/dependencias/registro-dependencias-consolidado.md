# Registro Consolidado de Dependencias - SIMFAT

Fecha: 2026-05-11

## 1. Backend principal (Spring Boot)

- Ruta: `Producto/backend/simfat-backend`
- Archivo fuente de dependencias: `pom.xml`
- Gestor: Maven
- Tipo de stack: Java / Spring Boot

## 2. Microservicio OpenEO (FastAPI)

- Ruta: `Producto/backend/openeo-service`
- Archivo fuente de dependencias: `requirements.txt`
- Gestor: pip
- Tipo de stack: Python / FastAPI

## 3. Frontend web

- Ruta: `Producto/frontend/simfat-web`
- Archivos fuente de dependencias:
  - `package.json`
  - `package-lock.json`
- Gestor: npm
- Tipo de stack: React + Vite

## 4. Nota de control académico

Este registro consolidado apunta a los archivos canonicos de dependencias por módulo.
Para Auditoría docente, se recomienda no incluir `node_modules` en el reporte manual y referenciar siempre los archivos de manifiesto indicados arriba.
